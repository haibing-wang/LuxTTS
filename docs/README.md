## ⚡ 核心特性一览

- **超高采样率 (48kHz)**：突破传统开源 TTS 常见的 24kHz 上限，使用定制 48kHz Vocos 声码器，带来录音室级别音质。
- **4 步流匹配蒸馏 (Flow Matching Distillation)**：将多步常微分方程（ODE）求解过程精简至 3~4 步，单卡推理速度突破 150x 实时。
- **极致轻量 (1GB VRAM)**：声学模型体积小，显存占用在 1GB 以内，主流消费级显卡、Mac MPS、甚至纯 CPU 均可畅跑。
- **全端推理支持**：
  - **CUDA (NVIDIA)**：PyTorch 原生加速。
  - **MPS (Apple Silicon)**：原生适配 M 系列芯片 Mac。
  - **CPU (ONNX Runtime)**：内置量化与 ONNX 算子，多线程无卡高速运行。
